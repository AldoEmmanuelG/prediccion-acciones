# Prediccion de la direccion diaria de acciones

Pipeline de Machine Learning de punta a punta (datos, validacion, modelos, app y contenedor) que estima la probabilidad de que una accion suba o baje al dia siguiente.

Proyecto final del Modulo 1, Diplomado en AI & LLM for Financial Markets (ITAM).
